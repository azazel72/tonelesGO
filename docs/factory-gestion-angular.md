# Factory Gestion (Angular)

Aplicacion independiente para gestion interna de fabrica.

## Desarrollo

1. Iniciar backend FastAPI en `http://localhost:5000`.
2. En `gestion/` ejecutar `npm start`.
3. Abrir `http://localhost:4200/`.

## Autenticacion

- Login REST: `POST /auth/login`.
- Token local de Angular: `gestion.auth.token`.

## Build

- Build estandar: `npm run build`.
- Build bajo subruta `/app`: `npm run build:app`.
